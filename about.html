업무 대시보드

자동화 장비 제작 업무를 위한 사내 전용 웹 도구

무엇을 하는 서비스인가요

장비 설계·제작 과정에서 반복되는 문서 작업을 한곳에서 처리하는 도구입니다. 승인된 회원만 로그인해 사용합니다.

  • 전장 도면 생성 — PLC·서보·I/O 구성 입력 → 전장 회로도(DXF·PDF)·BOM·I/O MAP 자동 작성
  • 공압 회로도 — 밸브·실린더 구성 입력 → 공압 회로도·부품표
  • 마스터 플랜·타임 차트 — 장비별 일정과 동작 시간표를 팀이 함께 편집
  • 검증 피드백 — 생성된 도면의 오류를 직원이 바로 보고하고 처리 결과를 받음

어떻게 동작하나요

화면은 브라우저에서 동작하고, 저장 데이터와 회원 정보는 운영자의 Google 계정에 있는 Google 스프레드시트·Drive 에 보관됩니다. 서버 역할은 같은 계정의 Google Apps Script 가 맡습니다.

사용 대상

운영자가 승인한 회사 구성원만 사용할 수 있으며, 일반 공개 서비스가 아닙니다.
